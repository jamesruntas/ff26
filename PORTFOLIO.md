# ADP Master

**A fantasy football draft board that refuses to trust any single source, plus a live draft assistant built on top of it.**

Every ADP tool has the same blind spot: it's one platform's mock-draft pool, presented as "the market." ADP Master pulls three genuinely independent feeds, Fantasy Football Calculator's public mocks, MyFantasyLeague's real home-league drafts, and ESPN's own platform drafts, reconciles them across three different player-ID schemes, and blends them into one consensus board without double-counting, since none of the three aggregates the others.

The interesting engineering lives in the seams. Each feed has a different depth and player universe, so raw ADP numbers aren't directly comparable; the pipeline rank-normalizes within each source before blending, reporting both the raw consensus pick and the scale-safe rank. FFC carries no shared player ID, so it's resolved by name, with a diagnostic that prints every unmatched player so gaps get fixed rather than silently dropped. Team defenses are a special case: the identity crosswalk everything else relies on doesn't carry them at all, so I built a separate resolution path matching defenses by team code, since a defense's identity is unambiguous in a way a person's name isn't. A validation layer treats a half-filled reference file as a hard crash rather than a plausible-looking wrong answer, on the theory that silent bad data is worse than a stack trace.

On top sits a live draft tracker: a Streamlit app run alongside a real or mock draft. It layers statistical modeling onto the raw ADP: tiers from rank-gap detection, a value signal tracking how far a player has fallen past consensus, and a survival-probability model, literally a normal distribution fit to each player's real ADP variance, estimating whether they'll last to your next pick. Falling value gets weighted by how depleted that player's tier is, so a player sliding in a thin position outranks a bigger raw fall in a deep one. A CPU opponent simulator drafts with weighted randomness rather than pure rank order, so mock drafts feel like drafts, not a sorted list read top to bottom. Draft-slot ownership is recomputed live rather than stored, so correcting a mistake mid-draft re-attributes your whole roster instead of leaving stale state behind.

Built in Python, with pandas driving the aggregation pipeline, scipy for the statistical modeling, and Streamlit for the interactive tracker. No paid data, no scraping workarounds, everything sourced from public, unauthenticated APIs, with the seams between them treated as the actual problem worth solving.
